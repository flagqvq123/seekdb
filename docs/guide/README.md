# MiniVectorDB 项目导读（给人看的版本）

> 这套文档是给你（学生/参赛者）读的，不是给评测器的。目标是让你在 10~20 分钟内
> 建立"这个仓库要做什么、现在做到哪、每一块怎么运转"的完整心智模型，然后能自己
> 做判断、提好问题、亲自验证——这也是赛题 Agent Prompt 项（40 分）真正在评的东西。

## 读法建议
- 先读 00 和 01，确认"值不值得继续投入"；再看 02+03，理解系统边界。
- 04/05/06 是技术核心，读到不懂的地方**记下问题**，不要直接问"帮我解释一下"，
  而是带着你自己的猜测来问（例如"我猜事务提交是写 WAL 后 fsync，对吗？"），
  这样才形成赛题要的"技术理解与迁移"证据。
- 07 是验证方法。每次 Agent 改完代码，你亲自跑一条命令确认结果，就是最有效的
  "独立验证"证据（比任何总结都值钱）。
- 08 是人机协作和 conversation.json 的玩法，建议和 09 一起看。

## 一句话记忆点
**输入是一条条 JSONL（SQL 包在 sql 字段里），输出是一条条 JSONL；所有数据必须落在
/data 且崩了能恢复；查询要按 L2 距离给出精确 TopK，过滤后再取 TopK，并列按主键升序。**
